
# Sound of Night

Ludum Dare 60 Compo Game, Theme: Old Tech

Learn Morse Code and decode messages to unravel a mystery.

Game contains complete in-game tutorial to learn Morse Code. Highly recommend playing through the entire tutorial if you have little experience with Morse Code before playing game. You can also watch the [YouTube video](https://youtu.be/XvJjCGevxq0?si=cPYnC0Y0_qeHdrdw) to see most of the tutorial.

Made by hand in less than 48-hours with C# and Godot. Web Export thanks to [2dog.dev](https://2dog.dev/). Sounds made in [BFXR](https://www.bfxr.net/).

[Dev log here](https://ldjam.com/users/mikeware/feed).

Known Issues:

- Rapidly clicking/pressing enter will skip messages and parts of game, please just follow along the journey, thanks!
